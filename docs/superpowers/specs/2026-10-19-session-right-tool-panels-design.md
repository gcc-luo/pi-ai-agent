# 会话右侧工具面板设计

## 背景与目标

当前聊天工作区在右侧提供可调整宽度的预览区，只能显示文件内容或知识库引用详情。用户希望在聊天旁并行使用文件浏览器、浏览器和终端，并要求 Agent 与用户操作同一个浏览器页面。

设计参考 [makecindy/cindy](https://github.com/makecindy/cindy) 的会话级标签、工具注册和资源生命周期；实现适配本项目 Vue、Fastify、Tauri 架构，不直接移植 Cindy 的 Electron WebView 或 Electron 主进程代码。

目标：

- 将现有右侧预览区扩展为会话级工具面板，不影响聊天区；面板最大宽度为屏幕宽度的一半。
- 提供文件浏览器、浏览器和终端三个持久工具标签。
- 让用户和 Agent 通过同一个会话浏览器查看、操作同一页面。
- 保留当前聊天文件预览和知识库引用预览行为。
- 在工具切换时保留仍打开工具的状态；关闭工具时释放其资源。

## 面板交互

- 工具面板位于聊天工作区右侧，使用现有右侧预览区的拖动分隔条和宽度约束。
- 面板未打开时，通过聊天区的面板按钮打开空状态。空状态提供“文件浏览器”“浏览器”“终端”入口；`+` 菜单支持点击外部或按 Esc 关闭。
- 打开工具后，顶部显示工具标签和 `+` 按钮。菜单始终显示可用工具，因此文件浏览器、浏览器和终端都可以各自打开多个标签。
- 每个会话最多 20 个标签，与 Cindy 一致。标签可拖动排序；右键菜单支持关闭其他标签或关闭所有标签。
- 关闭当前标签后优先激活其右侧标签，没有右侧标签时激活左侧标签。隐藏面板不会关闭标签或释放资源。
- 标签顺序、激活项、浏览器地址/标题/favicon、文件浏览器选中路径按会话保存在本机；面板宽度和文件树宽度保存在本机偏好中。
- 关闭标签会释放该工具实例。再次添加时创建新实例；关闭最后一个标签后收起面板。
- 工具标签和选中状态按会话隔离。切换会话不能串用其他会话的工具实例。

### 临时预览标签

现有聊天内容和文件列表都可以打开文件预览，聊天内容还可以打开知识库引用详情。两种预览复用一个自动创建的临时“预览”标签：

- 点击文件或知识库引用时，面板显示并选中“预览”标签。
- 再次点击其他文件或引用时，更新同一个预览标签的标题和内容，不新建标签。
- 文件使用现有 `FileViewer`，知识库引用使用现有 `KbCitationViewer`。
- 临时预览标签不在 `+` 菜单中。关闭后返回上一个持久工具标签；若没有其他标签，则收起面板。
- 文件浏览器内部选中的文件仍由文件浏览器自己的预览区域展示，不创建临时预览标签。

## 文件浏览器

- 浏览范围限定为当前会话所属项目的根目录，并复用现有项目级文件 API。
- 复用 `apps/web/src/components/FileTree.vue` 和 `FileViewer.vue`：按 Cindy 的内容区在左、文件树在右布局；分隔条可拖动，双击恢复默认宽度。
- 展开目录、选择文件，并在标签内预览内容；选中路径随标签保存。面板内不编辑文件。
- 提供刷新操作，以便在 Agent 写入文件后重新读取目录内容。
- 面板提供浏览和预览，不提供文件编辑、重命名或删除操作；文件修改沿用当前 Agent 和项目工作流。
- 切换标签时保留展开目录、选中路径和滚动位置。关闭后重新打开时创建新的文件浏览器实例。

## 浏览器

- 每个浏览器标签对应唯一的原生 WebView 和独立页面状态；使用当前激活的浏览器标签时，Agent 与用户操作同一页面。切换标签后，Agent 自动跟随当前激活标签。
- 浏览器标签使用原生 WebView 直接绘制网页，不以 JPEG 画面作为桌面端页面显示层。不同标签分别保留 URL、标题、favicon 和页面会话。
- 全局最多保留 5 个已物化的原生浏览器视图，优先回收最近最少使用的隐藏视图；标签和 URL 保留，重新激活时重建页面。所有标签总数仍按每会话最多 20 个限制。
- 新窗口/`target=_blank` 请求在应用内创建新的浏览器标签，不打开系统外部浏览器。
- 浏览器标签使用当前浏览器能力授权流程。打开面板不自动启用 `browser-use` 或改变插件权限。
- 关闭浏览器标签时释放对应 WebView 和页面流；重新打开时创建新标签实例。面板未打开时，Agent 仍按当前浏览器能力配置工作。
- 页面流和输入通道必须经会话身份验证，不将浏览器调试端口或无认证流直接暴露给其他会话。

## 终端

- 终端是用户使用的交互式 PTY，启动目录为当前项目根目录；它与 Agent 现有 shell 工具使用不同进程，不共享输入缓冲、工作目录或运行状态。
- 使用终端 UI 显示 shell 输出并发送输入，支持调整尺寸、键盘输入、中断命令和滚动查看。
- PTY 由项目服务端管理，通过经过会话身份验证的双向连接传输输入和输出；创建时以当前项目根目录为初始工作目录，客户端不能在连接参数中指定其他目录。
- 切换到其他标签时 PTY 继续运行。关闭终端标签时终止 PTY；重新打开时启动新 shell。应用重启后不恢复旧进程，重新打开终端创建新 PTY。
- WebSocket 临时断开时允许重新连接到当前仍存活的 PTY；会话终止或服务端退出时清理所属 PTY。

## 组件与状态边界

- 在 `apps/web/src/App.vue` 的聊天工作区中，以工具面板 Shell 替代目前由 `filePath` 和 `citationPreview` 单独驱动的右侧预览容器。
- 工具面板 Shell 负责宽度、空状态、标签栏、`+` 菜单、激活标签和关闭行为；各标签内容由独立组件承载。
- 文件列表和读取继续使用 `apps/web/src/api/client.ts` 及现有文件路由，不增加新的文件写入能力。
- 浏览器的 Agent 操作继续经现有浏览器扩展和服务端运行时；前端只连接该会话的经过授权的画面与输入通道。
- 新增终端 PTY 管理服务及 WebSocket 通道，进程生命周期以会话和终端标签为单位。客户端不能指定任意工作目录或任意会话 ID。
- 面板状态、预览目标和工具资源都按会话隔离。持久标签切换隐藏时不卸载资源；关闭时调用对应资源清理逻辑。

## 失败与恢复

- 文件列表或文件读取失败时，在文件浏览器或预览区域显示可重试的错误状态，不影响聊天及其他标签。
- 浏览器流断开时保留浏览器标签并提供重连状态；若底层实例已关闭，提示用户重开浏览器标签。权限关闭时不接受 Agent 浏览器操作。
- 终端连接断开时尝试连接回原 PTY；找不到原进程时提示终端已结束，并允许用户重新启动。
- 关闭会话时清理该会话的 PTY 和浏览器标签拥有的资源，避免跨会话残留。
- 切换标签不得重建其他活动标签，避免误终止终端或重置浏览器页面。

## 范围外

- Cindy 截图中“审查”“后台任务”等其他面板类型，本次不实现。
- 不实现 Cindy 中“审查”“后台任务”等本项目当前未包含的标签类型。
- 不把终端输入与 Agent shell 命令合并为同一 PTY。
- 不改变浏览器能力的启用状态或授权策略。

## 验收标准

- 面板可从聊天区打开，宽度可调且不超过屏幕宽度的一半；三个工具可从空状态或 `+` 菜单添加，`+` 菜单始终列出全部工具类型。
- 每个会话允许多个同类型标签，总数最多 20；切换标签保留状态，关闭标签释放对应资源，关闭最后一个标签后收起。
- 从聊天或文件列表打开文件、从聊天打开知识库引用时，内容在同一个临时预览标签中显示；连续选择不同内容复用该标签，关闭后返回原工具。
- 文件浏览器只能浏览当前项目内容，能预览文件并刷新 Agent 写入后的目录；不暴露写入操作。
- Agent 与用户的浏览器操作、页面导航和当前 URL 在同一会话中同步；不同会话之间的页面流、输入和授权互相隔离。
- 未启用浏览器能力时，打开面板不会隐式授予 Agent 浏览器能力；权限流程仍与现有行为一致。
- 用户终端启动于项目根目录，与 Agent shell 独立；切换标签保持 PTY，关闭标签终止 PTY，服务端或会话结束时清理 PTY。
- 原有文件预览、知识库引用预览、聊天和文件树行为不回退。
