# Token 用量弹框标签页交互设计

## 背景

当前会话累计 Token 入口和居中弹框已经可以工作，但弹框把汇总数据、最近调用和逐次调用明细纵向堆叠在同一视图中。调用次数较多时，首次打开需要滚动，关键数据和详细数据的层级也不够清晰。

本次只优化弹框展开后的内容样式与交互。入口位置、入口上的会话累计及输入/输出统计、统计口径和居中弹框形态均保持不变。

## 范围

### 包含

- 将弹框内容划分为“概览”和“调用明细”两个标签页。
- 默认打开“概览”，突出本次和会话累计的输入/输出 Token。
- 将缓存读取、最近一次调用和“压缩上下文”放入概览页的次级信息区域。
- 将逐次模型调用表格独立到“调用明细”页，保留模型、输入、输出、缓存和工具调用字段。
- 通过标签按钮的选中态、下划线和可访问属性表达当前页。
- 保留右上角关闭、点击遮罩关闭和 Esc 关闭；弹框内容较长时只在弹框内部滚动。
- 为新增标签文案和无调用明细状态补充中英文文案。

### 不包含

- 不调整 Token 用量入口的位置、外观和摘要数字。
- 不修改 `summarizeTokenUsage()`、消息去重逻辑、Token 统计口径或服务端接口。
- 不新增数据库字段、网络请求或持久化状态。
- 不改变“压缩上下文”的执行逻辑和禁用条件。
- 不改造其他弹框或全局表格样式。

## 设计方案

### 1. 弹框结构

弹框保留现有标题栏、说明文字和关闭按钮。说明文字下方增加标签栏：

1. **概览**：默认选中，展示本次请求和会话累计的输入/输出 Token 卡片；缓存读写和模型/工具调用作为辅助信息展示；继续提供最近一次调用和压缩上下文操作。
2. **调用明细**：展示当前请求的逐次调用表格。表格保留现有数据字段和格式化规则，内容过宽时在表格区域横向滚动，内容过长时由弹框主体纵向滚动。

概览页使用两列指标卡建立“本次 / 会话累计”和“输入 / 输出”的视觉分组，输入沿用蓝色、输出沿用橙色。调用明细页不再默认展开在概览下方，避免打开弹框时出现过长的首屏。

弹框说明使用简短文案“查看本次请求与整个会话的 Token 消耗。详细的逐次模型调用记录放在“调用明细”中。”，只说明信息范围，不在首屏重复统计口径。概览页底部将“压缩上下文”按钮与说明放在同一操作行，按钮左对齐、说明右对齐；窄窗口下改为上下排列以保证可读性。

### 2. 交互行为

- 每次打开弹框默认进入“概览”，不保存跨打开的标签页状态。
- 标签使用原生按钮，附带 `role="tab"`、`aria-selected` 和对应 `tabpanel`，键盘可通过 Tab 聚焦并切换。
- 切换标签只改变弹框内部内容，不关闭弹框、不改变统计数据。
- 关闭按钮、遮罩点击和 Esc 保持当前行为；关闭后焦点返回 Token 用量入口。
- 当没有逐次调用数据时，“调用明细”标签仍可进入，并显示明确的空状态，不渲染空表格。

### 3. 数据与错误处理

`TokenUsageSummary` 仍是唯一数据来源。概览页直接读取 `session`、`current` 和 `latest`，调用明细页读取 `calls`。数字继续通过 `formatTokenCount()` 显示，缺失缓存数据继续显示 `—`。

本次不引入新的异步操作，因此不增加加载或失败状态。已有压缩按钮继续受 `busy` 和会话模型调用次数控制；压缩成功、失败和运行中状态由现有流程处理。

### 4. 组件边界

- 修改 `apps/web/src/components/TokenUsage.vue`：负责标签页状态、弹框内部展示、可访问属性和局部样式。
- 修改 `apps/web/src/i18n/messages.ts`：增加概览标签和无明细状态的中英文文案。
- 修改 `apps/web/tests/unit/chat-panel-running-input.test.ts`：保持入口位置断言与现有会话累计统计验证。
- 新增或修改 `apps/web/tests/unit/token-usage.test.ts`：覆盖默认概览、标签切换、调用明细、空状态和关闭行为。

## 测试策略

使用 Vue Test Utils + Vitest 验证：

1. 弹框初始打开时概览标签选中，汇总指标可见，调用明细内容不在概览首屏渲染。
2. 点击调用明细标签后，标签选中态切换，逐次调用表格和调用次数可见。
3. 没有调用记录时，调用明细页展示空状态，不出现空表格。
4. 右上角关闭按钮、遮罩点击和 Esc 仍可关闭弹框。
5. 入口仍显示会话累计输入/输出统计，原有实时统计测试继续通过。
6. 概览说明使用简短文案，压缩按钮和提示语位于同一操作行。

验证命令：

```bash
pnpm --filter @pi-web-ui/web test
pnpm --filter @pi-web-ui/web typecheck
pnpm --filter @pi-web-ui/web build
```

## 验收标准

- 点击当前 Token 用量入口后，弹框仍居中显示，入口位置和摘要数字不变。
- 弹框默认只突出汇总信息；逐次调用明细通过第二个标签页访问。
- 标签切换、关闭、Esc 和遮罩关闭在鼠标与键盘操作下均可用。
- 浅色、深色和灰色主题下标签、指标、表格和空状态保持可读。
- 统计数据、压缩上下文操作和现有会话行为不发生变化。
