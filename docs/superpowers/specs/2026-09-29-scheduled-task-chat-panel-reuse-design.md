# 定时任务复用 ChatPanel 设计

## 目标

定时任务的“自动提问”编辑弹框直接复用当前会话 `ChatPanel` 的对话输入区和工具栏，让用户使用与普通会话完全一致的技能、插件、连接器、专家能力选择体验。定时任务保存这些选择的快照，在每次执行时按快照调用；失效能力被跳过并写入执行日志警告。

“定时提醒”继续保持纯文本提醒，不调用 Agent，也不显示 AI 能力选择。

## 交互设计

- 自动提问任务的弹框包含任务名称、描述、执行计划、目标项目、会话复用策略和启用开关。
- 提示词输入区和其上方的工具栏使用从 `ChatPanel` 抽出的共享组件，沿用原有 DOM 结构、样式、按钮顺序、弹出选择器和交互。
- 技能、插件、连接器支持多选；专家支持单选；知识库保持当前会话能力选择，不纳入本次定时任务能力快照，避免把会话资料绑定语义与任务能力混在一起。
- 保存时将当前草稿中的技能名、插件 ID、连接器 ID、专家 ID 写入任务快照；编辑时恢复快照。
- 定时提醒只显示现有提醒文本输入，不渲染 ChatPanel 工具栏。

## 数据模型

共享类型新增：

```ts
export interface ScheduledTaskCapabilities {
  skillNames: string[];
  pluginIds: string[];
  connectorIds: string[];
  expertId: string | null;
}
```

`ScheduledTaskDto` 增加 `capabilities` 字段。数据库通过新迁移增加 `capabilities_json TEXT NOT NULL DEFAULT '{}'`。旧任务读取为空快照，保持兼容。

任务 payload 仍只保存任务类型正文：自动提问保存 `{ prompt }`，提醒保存 `{ message }`；能力快照独立保存，避免把 UI 选择标记混入提示词。

## 组件边界

- 新建共享 `ChatComposer` 组件，承接 `ChatPanel` 当前输入框、附件区域、技能 chip、工具栏和相关选择器；支持普通会话发送模式与定时任务草稿模式。
- 普通会话模式继续读写 session 的插件、专家和会话能力状态，发送后保持现有行为。
- 定时任务草稿模式使用受控值，不修改真实 session；组件向父组件输出提示词、技能名、插件 ID、连接器 ID 和专家 ID。
- `SkillSelect`、`PluginSelect`、`ConnectorSelect`、`ChatExpertPicker` 保留现有视觉实现，增加受控草稿模式所需的 `modelValue`/事件接口；默认模式保持兼容。
- `CreateScheduledTaskDialog` 负责调度字段与草稿保存，不自行复制 ChatPanel 的按钮或选择器样式。

## 服务端执行流程

1. 创建或复用任务会话。
2. 根据能力快照解析当前仍有效的技能、插件、连接器和专家。
3. 对无效、禁用或不存在的能力过滤，并生成中文警告。
4. 将有效插件写入任务会话的插件选择；将专家写入任务会话的专家配置。
5. 将有效连接器 ID 设置为该任务会话的临时访问范围。连接器搜索、描述和调用都必须校验该范围；未进入快照的连接器不可被 Agent 使用。
6. 将有效技能以当前 ChatPanel 使用的 `/skill:<name>` 标记附加到实际发送给 Agent 的内容，持久化的用户消息保留干净的原始提示词。
7. 执行完成后保留会话和日志；连接器访问范围在运行结束后清理。

普通会话不设置任务访问范围，继续使用当前项目下已启用连接器。任务执行仍沿用现有重试和超时策略。

## 失效能力与日志

- 技能不存在、插件未启用/不可用、连接器不存在/禁用/不属于目标项目、专家不存在时，均从本次运行中移除，不阻断 Agent。
- 任务日志输出增加“能力警告”段落，列出被跳过的类型、名称和原因。
- 若所有能力均失效，任务仍执行原始提示词；只有 Agent、本身项目或调度执行失败才将任务标记为失败。

## API 与校验

- 创建和更新接口接受 `capabilities`，要求数组去重；专家只接受字符串或 null。
- 服务端只持久化 ID/名称快照，不信任客户端传来的显示名称或描述。
- 自动提问任务允许能力快照；提醒任务忽略并清空能力快照。
- 返回 DTO 时总是提供完整的空数组/null 结构，保证旧客户端和新客户端兼容。

## 测试策略

- 共享类型与 repository：覆盖空快照、读写快照、旧任务兼容和更新保留。
- 路由：覆盖创建/更新能力校验、提醒任务清空能力、旧 payload 兼容。
- 任务执行：覆盖技能标记拼接、插件/专家会话配置、连接器 allowlist，以及失效能力跳过并记录警告。
- 连接器服务：覆盖任务会话只能搜索、描述和调用快照内连接器，普通会话行为不变。
- 前端：覆盖定时任务弹框恢复/提交能力快照；覆盖 `ChatComposer` 在普通会话和草稿模式下共享工具栏行为。
- 最终运行全量 `pnpm test`、`pnpm typecheck` 和 `pnpm build`。
